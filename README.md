# photo-culling

교육 세션마다 찍는 연사 사진(회차당 ~100장) 중에서 눈 감지 않고 표정 좋은 베스트 컷을
자동으로 골라주는 아카이빙 도구입니다. 원본은 절대 건드리지 않고, 선택된 사진만 지정한
출력 폴더로 **복사**합니다.

## 동작 방식

1. 폴더 안 사진들의 촬영시각(EXIF, 없으면 파일 수정시간)을 읽어 정렬합니다.
2. 촬영 간격이 `--gap`초 이내로 붙어 있는 사진들을 하나의 "연사 그룹"으로 묶습니다.
3. 그룹 안의 각 사진에 대해 다음을 계산합니다.
   - **선명도**: 라플라시안 분산 기반 (흔들림/블러 감지)
   - **눈뜸 정도**: 얼굴 68포인트 랜드마크로 Eye Aspect Ratio 계산. 화면에서 가장 큰
     얼굴(주요 인물)이 눈을 감았으면 강한 감점.
   - **표정 점수**: happy/surprised는 가점, sad/angry/disgusted는 감점.
4. 그룹 내에서 점수가 가장 높은 사진 1장을 선택하고, 2위 사진이 1위와 점수 차이가
   `--closeness` 비율 이내로 근접하면 (기본 90% 이상) 2위까지 함께 선택합니다.
   (그룹당 최대 2장, 최소 1장 — 얼굴이 없는 그룹/단독 컷은 선명도만으로 판단)
5. 선택된 사진을 `--out` 폴더로 복사하고, 모든 사진의 점수를 `report.csv`로 남깁니다
   (선택/탈락 사유 포함 — 아카이빙 근거 기록용).

## 지원 포맷

JPEG, PNG, HEIC/HEIF(아이폰), TIFF. **RAW 원본(CR2/NEF/ARW 등)은 지원하지 않습니다** —
카메라에서 JPEG로 동시 저장하거나, 먼저 JPEG로 변환한 폴더를 입력으로 사용하세요.

## 사용법

```bash
cd ~/photo-culling
node cull.js <입력폴더> --out <출력폴더> [옵션]
```

예시:

```bash
node cull.js ~/Pictures/2026-09-03_수업 --out ~/Pictures/2026-09-03_수업_선별
```

### 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--out <dir>` | `./selected` | 선택된 사진을 복사할 폴더 |
| `--gap <초>` | `1.5` | 같은 연사로 묶을 촬영 간격(초). 카메라 연사 속도가 빠르면 줄이고, 사진 간 텀이 있으면 늘리세요 |
| `--closeness <0~1>` | `0.9` | 1위 대비 이 비율 이상 점수면 2위도 함께 선택 (낮출수록 2장 선택이 잦아짐) |
| `--dry-run` | - | 실제 복사 없이 `report.csv`만 현재 폴더에 생성 (미리 결과 확인용) |

먼저 `--dry-run`으로 결과를 확인한 뒤, 만족스러우면 옵션 없이 다시 실행하는 것을
추천합니다.

## report.csv 컬럼

- `group`: 연사 그룹 번호
- `file`: 원본 파일명
- `faces`: 검출된 얼굴 수
- `sharpness`: 선명도 원점수 (그룹 내 상대 비교용)
- `eyeScore`: 0~1, 1에 가까울수록 눈을 잘 뜸
- `exprScore`: 0~1, 1에 가까울수록 표정이 좋음(happy/surprised)
- `composite`: 최종 종합 점수
- `status`: 선택 / 탈락
- `reason`: 선택 순위 또는 탈락 사유 (예: "주요 인물 눈 감음", "심한 블러")

## 처음 실행 시 참고

모델 로딩에 첫 실행 시 약 0.5~1초가 걸리고(오프라인 동작, 인터넷 불필요), 사진 1장당
분석에 대략 0.2~1초 정도 걸립니다. 100장 기준 전체 실행에 수 분 이내로 예상하시면 됩니다.

## 튜닝이 필요할 때

- **2등 사진이 잘 안 골라짐** → `--closeness`를 0.85 등으로 낮춰보세요.
- **그룹이 너무 잘게 쪼개짐(연사인데 따로 묶임)** → `--gap`을 2~3초로 늘려보세요.
- **다른 사람이 우연히 화면에 잡혀 눈 감았다고 억울하게 탈락함** → 현재는 화면에서
  가장 큰 얼굴만 "주요 인물"로 취급해 감점하므로, 보통은 문제되지 않습니다. 계속
  문제가 되면 `lib/vision.js`의 `mainFace` 판단 기준(면적 최대 → 예: 상위 2명 평균)을
  조정할 수 있습니다.
